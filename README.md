## 📂 Repository Directory Index

This repository contains the laboratory assignments and midterm project for CSC-334:

### 1. 🚀 [Midterm Project: Distributed GPU Task Offloading & Remote Video Processing](midterm%20project/)
- **Location:** [`midterm project/`](midterm%20project/)
- **Tech Stack:** Python 3.10+, FastAPI, Uvicorn, PyQt6, NVIDIA NVENC, FFmpeg, WebSockets, HTTP Chunked Streaming.
- **Description:** A distributed client-server task offloading framework that delegates computationally heavy video transcoding from a resource-constrained client machine to a remote GPU-accelerated worker node over LAN/Wi-Fi with zero-RAM streaming and SHA-256 verification.
- **Documentation:** See full project specifications and architecture in [`midterm project/README.md`](midterm%20project/README.md).

### 2. 🔌 [Lab 03: Socket Programming with Multi-Threading](labtask_1/)
- **Location:** [`labtask_1/`](labtask_1/)
- **Tech Stack:** Python Standard Library (`socket`, `threading`, `time`).
- **Description:** Multi-client concurrent TCP server utilizing dedicated per-client worker threads and `threading.Lock` mutual exclusion for thread-safe state synchronization.
- **Documentation:** See [`labtask_1/README.md`](labtask_1/README.md).
